# Data Dictionary

## Project Overview
This folder contains synthetic datasets for the Macy's Wedding Registry Data Platform portfolio project. All records are fictional and created for educational purposes.

## Datasets

| File | Description |
|---|---|
| `customers.csv` | Customer demographic and location information |
| `products.csv` | Registry products, categories, brands, and prices |
| `registries.csv` | Wedding registry creation dates, wedding dates, and statuses |
| `registry_items.csv` | Products requested and purchased for each registry |
| `guests.csv` | Fictional wedding guest information |
| `purchases.csv` | Gift purchase transactions |
| `returns.csv` | Returned gift transactions and reasons |
| `gift_tracker.csv` | Gift delivery and tracking statuses |
| `thank_you_notes.csv` | Thank-you note statuses and sent dates |

## Data Quality Goals
- Check for duplicate IDs.
- Validate relationships between datasets.
- Identify missing or invalid values.
- Verify that quantities and prices are valid.
- Ensure purchase and return records are consistent.

## Disclaimer
This is an independent educational portfolio project. It uses synthetic data and is not affiliated with Macy's or based on Macy's internal or customer data.
