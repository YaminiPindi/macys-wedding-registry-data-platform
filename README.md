# macys-wedding-registry-data-platform
End-to-end e-commerce data engineering, analytics, and machine learning project based on a synthetic wedding registry dataset.
Macy’s Wedding Registry Data Platform

Project Overview

This project simulates an e-commerce wedding registry platform using synthetic data inspired by publicly documented retail workflows.

Project Goals

* Build a data engineering pipeline using Python.
* Store and manage data using PostgreSQL.
* Perform data quality checks and SQL analytics.
* Create business dashboards using Power BI.
* Explore machine learning for purchase prediction and product recommendations.

Technology Stack

* Python
* SQL
* PostgreSQL
* Power BI
* Machine Learning
* Git and GitHub

Data Disclaimer

This project uses synthetic data for educational and portfolio purposes. It is not affiliated with Macy’s and does not use Macy’s internal or customer data.
